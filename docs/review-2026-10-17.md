## Findings and resolutions

| ID | Severity | Reproduction and consequence | Resolution and evidence |
| --- | --- | --- | --- |
| R1 | High | Calling public `Database::parsed` directly with `root/../outside/file` or an in-root symlink to an outside file could read outside the granted source root. Validation existed in higher-level callers, not every public query. Canonical aliases could also receive different cache keys. | Normalize and validate `parsed`, `modules`, `prepare`, and `analyze` before cache lookup or source reads. Regressions reject traversal/symlink escape with zero reads and prove canonical alias reuse. Open overlays retain their previously authorized identity after disk deletion/replacement; closing revokes that authority. |
| R2 | High | Two `ResourceTable<T>` instances can both allocate slot 0, generation 1, borrow 1. A token from one table previously released, read, mutated, or ended a borrow in the other. | Private, never-reused table provenance is part of owned/borrowed token validation. | R3 | Medium | With a one-file database budget, a rejected oversized document open allocated a file-key slot, preventing a later valid file from opening. | Preflight the aggregate input-byte limit before allocating keys. `rejected_open_does_not_consume_the_file_budget` verifies recovery. |
| R4 | Medium | Relative object/output filenames beginning with `@` were interpreted as response files; leading `-` object names became options. Quoting an argument does not stop driver-level interpretation. | Prefix those relative path arguments with the current-directory component. Direct and response-file commands share the conversion. Tests check both driver flavors and actually compile, link, and run both filename cases on macOS. |
| R5 | Medium | RFC 0001 described implemented component/source features as unspecified; RFC 0002 still treated lexical rules and visible booleans as unresolved; RFC 0006 called its compatibility fixtures nonexistent. | R6 | Medium | The roadmap began ownership implementation before its source grammar gate, hid core-library and full copy-profile native work, and listed C embedding stabilization before production conformance. | R7 | Low | Root `cargo fmt --all --check` excludes `fuzz/`. Two fuzz targets were unformatted despite a passing root baseline. | Format them, check separate-workspace formatting in both tier-1 workflows, and lint fuzz binaries with warnings denied on macOS. Document both local commands. |
