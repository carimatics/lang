## Review method and limits

All 581 baseline files were included in inventory and content checks, with seven additions checked separately. Whole-repository structural checks complement manual contract and implementation review; this is not formal verification or a fresh fuzz campaign. The groups include generated evidence and fixtures.

- Trace parser/diagnostic spans, name/type/ownership resolution, query invalidation and LSP framing to acceptance and malformed-input tests.
- Check independent MIR/bytecode admission: count/byte/work budgets, canonical tags, source-independent ownership/loan/region proofs, cleanup elaboration and immutable verified types.
- Check runtime/VM allocator identity, reserve-before-effect rules, generation/borrow/region validity, iterative retirement, first-failure precedence, poison/retry and finite instruction/service controls.
- Inspect native unsafe entry/binding/allocator/export boundaries, matching image lifetimes, owner-thread C contexts, publication and debugger assertions. R03 comes from comparing a normative requirement with actual probe assertions.
- Reconcile every RFC lifecycle state, roadmap dependencies/priorities/arithmetic, translations and historical evidence. Old architecture/roadmap bodies are retained exactly apart from link retargeting.
- Parse all 28 JSON captures/fixtures, 18 TOML/lockfiles and seven Python files in the resulting tree. Resolve Markdown/translation targets and 286 literal test/fuzz fixture inclusions. Recompute M2 benchmark summaries without modifying captures. The only ignored Rust test is the explicitly observational timing probe.

## Findings and resolutions

- **R01 — Completed milestone still mandated for new work.** The previous AGENTS/CONTRIBUTING procedure required new work to use the completed M2 board. It now uses the active milestone or a scoped maintenance/review checklist, preserves M2 as a completion record and avoids mandatory standalone planning commits.
- **R02 — Historical checkpoints obscure current architecture.** Separated current contracts from dated implementation history and verified the resulting references. The routinely read English architecture shrank from 394,354 bytes to about 15 KiB (about 96%); historical bodies remain intact.

- **R03 — Missing owned logical-stack debugger evidence.** RFC 0012 required the logical guest chain, but the G03/G18 probe checked only physical runtime callers. Added the missing read-only descriptors, verified three live logical frames and parent call sites on both actual hosts, then marked RFC 0012 implemented. No normative requirement was weakened.


- **R04 — RFC states and index lag implementation.** Reconciled completed evidence for 0007–0010, 0013 and 0015 and marked them implemented; 0012 followed after R03 closed. Added missing README entries 0014/0015, current-state notes for implemented RFCs, and a regression test for missing, duplicate or stale index statuses.
- **R05 — Incorrect translation metadata targets.** Four Japanese documents pointed to nonexistent Japanese-side paths. Corrected translation-of to their canonical documents and aligned review dates in both languages.
- **R06 — Priority contradicts a mandatory exit.** Promoted M4's installer from P1 to P0 because its exit requires a new developer to install one tool. Scope and point totals are unchanged.
- **R07 — Regression checks excluded from routine CI.** Actual native debugger validation now runs for relevant PR/main changes instead of relying on manual runs. Added the seven benchmark harness validator tests to routine macOS CI.
