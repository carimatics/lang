## Effective C limit scope

Engine ceilings govern pre-instance module/registration preparation. A root call uses the fieldwise minimum of engine, instance and one-shot control; children retain that root's original counters and effective policy. Zero is a real bound. Optional report limits truncate evidence without stopping cleanup.

| service_work | shared ServiceWork | Existing enforcement retained |
| host_calls | Control / original invocation | Existing enforcement retained |
